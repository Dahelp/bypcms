# BYPCMS

Новая версия платформы для индивидуальных сайтов: стабильное ядро,
изолированные модули и отдельный слой клиентского проекта.

## Что уже работает

- продуктовая главная с редакциями Business, Commerce и Content;
- адаптивный интерфейс для телефона, планшета и компьютера;
- интерактивный прототип панели на `/admin`;
- отображение лицензии, состояния ядра, модулей и обновлений;
- статическая production-сборка;
- автоматический FTP-деплой через GitHub Actions.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Production-сборка для FTP

```bash
pnpm build:ftp
```

Результат создаётся в `out/`. Workflow использует секреты `FTP_USERNAME` и
`FTP_PASSWORD`, сервер `grass.gohost.ru` и не сохраняет доступы в репозитории.

Подробная схема ядра, модулей, лицензирования и обновлений описана в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
