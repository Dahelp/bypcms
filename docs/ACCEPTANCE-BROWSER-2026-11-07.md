# Браузерная приёмка BYPCMS — 7 ноября 2026

## Проверенные пути

Проверка выполнена во встроенном браузере после его подключения. Для узких
экранов использованы viewport 390 × 844 и тестовые iframe той же ширины:
это проверка реального CSS/DOM в браузере, не испытание на физическом телефоне.

На опубликованном demo.bypcms.ru, в изолированных данных текущего браузера:

- Новый материал начинается без выбранной обложки; предпросмотр доступен без
  создания записи. В нём отображаются введённые название и описание.
- Из предпросмотра «Назад» возвращает к форме с теми же данными и вкладкой SEO.
  Повторное открытие и «Закрыть» дают тот же результат. Проверена штатная
  навигация истории браузера; физическая боковая кнопка мыши отдельно не нажималась.
- Настройки SEO открываются по шестерёнке без страницы входа. Выбор Яндекса
  сохраняется, возврат к материалу сохраняет черновик и показывает Яндекс.
  По окончании восстановлено исходное предпочтение Google.
- Медиапикер при 390 px: поиск по имени, отсутствие результатов, просмотр
  выбранного фото, применение обложки, подпись «Заменить изображение» и корзина.
- Пустое название и пустой адрес вызывают ошибку без потери описания/обложки.
  После заполнения адреса сохранение открывает редактор созданного ID.
- В существующем материале несохранённый заголовок отображается в предпросмотре;
  «Назад» сохраняет тот же ID, заголовок и активную вкладку SEO.
  Кнопка «Материалы» открывает список, где видна сохранённая версия заголовка.

На изолированном PHP/Apache/MariaDB-стенде (порты 8019, 8029, 3319):

- Форма лицензии Owner: desktop и 390 px; годовой/пожизненный срок, смена цены,
  скрытие/возврат даты окончания. Боевые ключи не использовались.
- Owner → Выпуски CMS: открытие и отмена подтверждения публикации, Escape,
  повторное открытие; публикация подготовленного 2.1.9 только в тестовый каталог.
- Клиентский Admin → Обновления: проверка каталога/лицензии → подтверждение →
  копия 265 файлов и 28 таблиц → установка 2.1.9 → перезагрузка рабочей панели.
- Мобильный Admin: предупреждение о потере последующих изменений, начальный фокус
  на «Отмена», подтверждение ручного отката, блокировка повторного запуска,
  отображение этапа восстановления → возврат версии 2.0.0.
- После отката отдельно сравнены DDL и все строки каждой из 28 таблиц с gzip-копиями
  именно этой операции; SHA-256 конфигурации, файла загрузки и файла проекта совпал.
- Независимое восстановление: рабочий экран во время обновления, завершённая
  история после отката на ПК и при 390 px; нет продолжения/повторного отката
  для завершённых, неактуальных или не начавшихся операций.

## Исправления по результатам проверки

1. Подтверждение обновления/публикации было после всего списка выпусков и истории.
   При длинном списке его не было видно. Теперь это общий нативный dialog для
   Owner/Admin с фокусом на отмене, Escape до запуска, прогрессом и ошибками внутри.
   Во время работы действия повторного запуска и отмены заблокированы.
2. Независимый экран при глобальном maintenance показывал «Продолжить» у каждой
   исторической операции. Кнопки теперь зависят от состояния конкретного процесса;
   ручной откат завершённого выпуска доступен только для текущего release.
   Состояния/этапы переведены, добавлены текущая версия, дата и мобильные отступы.
3. У несохранённой записи демо убраны удаление и его подтверждение. В редакторах
   материала и страницы список статусов ограничен «Черновик/Опубликовано/Скрыт».

## Проверки сборки и границы

45 регрессионных проверок редактора, медиатеки, сессий, таблиц, API-запросов и
установщика; production export/TypeScript; ESLint UpdateSettings; PHP lint recovery.
Скриншоты и тестовые данные находятся в игнорируемом outputs/acceptance/.

Реальная внешняя клиентская установка, боевые ключи, публикация выпуска всем
клиентам и реальные оплаты не использовались. Выкладка самой платформы/demo
идёт штатным CI/FTP; её итог и повторная проверка боевых маршрутов приводятся
в сообщении о завершении. Реальная оплата/уведомления и соответствие девяти тем
заявленным возможностям остаются следующими этапами общей приёмки.
