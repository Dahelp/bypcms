# Gallery: дополнительная приёмка и исправления 2.3.1

Пользователь запросил визуальный прогон покупателя на 360, 390, 768 и 1440 px, исправление найденного, commit/push и публикацию. Инструмент управления вернул пустой список браузеров и `Local browser use is disabled in Work settings`. Ранее предоставленный скриншот показывает включённый переключатель; причина расхождения не установлена. Пользователь выбрал «Продолжай доступные проверки». Блокировку не обходили другими средствами автоматизации браузера.

## Исправлено

1. **Копейки в стоимости.** Shop и Gallery округляли отображаемую сумму до целого рубля. Теперь общий formatter сохраняет две десятичные позиции при наличии копеек; целые суммы по-прежнему показываются без лишних нулей. Денежные расчёты и сумма запроса провайдеру остаются целыми копейками.
2. **Ценовые фильтры.** Вместо приведения к целому числу рублей границы разбираются в копейки. Доступен шаг 0.01. Принимается точка или запятая. Некорректные значения и обратный диапазон показывают ошибку и не раскрывают полный каталог как будто фильтр сработал. Ссылки пагинации сохраняют границы в рублях.
3. **Переход к оплате и CSP.** На странице заказа разрешены HTTPS-источники ЮKassa/ЮMoney, прошедшие ограничения провайдера. Обычные страницы, включая публичное showcase, сохраняют `form-action 'self'`. Иначе браузер, проверяющий redirect после POST, может блокировать подтверждённый сервером переход к провайдеру. Поведение редиректов при этой директиве различается между браузерами: [MDN form-action](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/form-action).

Локальный платёжный origin разрешается только из защищённой debug-конфигурации, только для заказа, только `127.0.0.1` с допустимым портом. Query-параметр посетителя не меняет CSP. `script-src 'self'`, запрет внешнего framing и остальные ограничения сохранены.

## Фактически проверено

| Проверка | Результат |
| --- | --- |
| PHP: Gallery, точные суммы, диапазоны и границы CSP | 164 проверки прошли |
| Товар 37,45 ₽ × 3, скидка WELCOME, самовывоз / доставка | Проверено HTTP на отдельном установленном Commerce |
| Карточка → корзина → оформление → заказ → тестовая оплата → подтверждение | `tests/shop-currency-http.mjs`: 28 проверок прошли |
| Окончательный итог | 1 001,12 ₽ в HTML; `1001.12 RUB` у локального провайдера |
| Ошибка email, неверный промокод, неправильный диапазон, повтор оплаты и checkout | Проверено HTTP; ввод сохраняется, повтор не создаёт второй платёж |
| CSP в реальном ответе заказа | Есть источники провайдера и только настроенный loopback; подстановка origin через URL не действует |
| Основной путь покупателя, вариант без остатка, удаление/возврат в корзину, собственный заказ, конкуренция за последний товар | `tests/shop-http.mjs`: 51 проверка прошла |
| Journal и Atelier | PHP-регрессии renderer; HTTP-проверки боевых маршрутов выполняются после деплоя |

HTTP-тест не исполняет CSP браузерным движком. Он подтверждает заголовок, redirect, серверную сумму и результат провайдера; это не подтверждение фактического перехода в Chromium.

## Не пройдено

- Реальная визуальная геометрия и читаемость на 360 / 390 / 768 / 1440 px, отсутствие горизонтального переполнения.
- Мобильное меню, увеличение изображения, Escape, возврат фокуса и клавиатурная навигация в браузере.
- Браузерные Back/Forward, боковая кнопка мыши, восстановление формы из bfcache.
- Фактическое применение CSP и полный переход к тестовой оплате браузерным движком.
- Новые скриншоты Gallery, Journal и Atelier; Web Vitals.

Эти пункты остаются открытыми до восстановления инструмента Browser Use. HTTP-ответы, анализ кода и старые скриншоты не выдаются за визуальную приёмку. Реальные платежи и письма не отправлялись; локальные данные и доказательства остаются в игнорируемом `outputs/gallery-acceptance/`.
