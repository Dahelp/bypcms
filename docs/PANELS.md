# Общий интерфейс панелей

Demo, Owner и Admin используют `app/components/PanelTable.tsx` и `app/panel-tables.css`.
Название записи — прямая ссылка в редактор. Справа находится настоящее меню «⋯»
с текстовыми действиями. Опасные действия выделяются красным и требуют подтверждения.
Меню содержит только операции, которые поддерживает соответствующий раздел/API.

В каждой таблице есть выбор строки, выбор всех отображаемых строк, частичное
состояние общего чекбокса, счётчик и сброс выбора. Выбор относится к отображаемым строкам;
скрытые фильтром или сменой страницы строки в действие не попадают. Разные таблицы выбираются независимо.
Колонка действий закреплена справа при горизонтальной прокрутке. Для меню доступны
стрелки, Home/End, Escape и Tab; меню не обрезается границами таблицы.

После выбора строк появляется панель «Действие → Применить». Для всех таблиц доступен
экспорт выбранных строк в CSV. Для контента — публикация, черновик и архив/скрытие;
для работ, клиентов и лицензий — допустимые статусы соответствующего типа; для
установленных модулей — включение/выключение, для каталога модулей — публикация/черновик/архив.
Удаление доступно для контента, концепций, портфолио и записей демо-модулей.
Договорные записи и лицензии закрываются/скрываются сменой статуса.

Перед изменением данных показываются действие, количество и названия записей;
удаление отмечено как необратимое. До подтверждения можно отменить операцию. Во время
запроса повторный запуск и изменение выбора блокируются. После обработки показывается
результат, успешные записи снимаются с выбора, ошибочные остаются выбранными.

API `POST panel.bulk` использует существующую авторизацию и CSRF. Коллекции, ID,
операции и статусы проверяются по разрешённым значениям. Owner-коллекции доступны
только владельцу. Одна запись и запись аудита сохраняются в одной транзакции;
ошибка одной записи не откатывает остальные. Смена статуса страницы сохраняет ревизию,
завершение/повторное открытие работы согласует прогресс и дату завершения. Удаление
системных страниц и страниц с дочерними записями запрещено. Выбор более 200 записей
отправляется последовательными пакетами с сохранением промежуточного результата.

## Маршруты

Переходы используют обычные `<a href>` и загружают документ. URL — источник состояния
раздела и редактора. Панели не вызывают `history.pushState`/`replaceState` и не
перехватывают `popstate`. После успешного сохранения Demo открывает редактор сохранённой
записи; Owner/Admin возвращаются к списку.
JavaScript остаётся для форм, запросов API, фильтров и локальных инструментов редактора.

| Панель | Список | Редактор | Создание |
| --- | --- | --- | --- |
| Demo | `?edition=content&section=pages` | `?edition=content&section=pages&record=3` | `?edition=content&section=pages&editor=new` |
| Owner | `?section=clients` | `?section=clients&editor=client&record=1` | `?section=clients&editor=client` |
| Admin | `?section=content` | `?section=content&page=1` | `?section=content&editor=new-page` |
| Концепции Admin | `?section=concepts` | `?section=concepts&concept=1` | `?section=concepts&concept=new` |

У модулей Admin используется `?section=modules&module=seo`. У подключаемых модулей
Demo — `?edition=business&section=faq&entry=1` и `entry=new`. Сохранённая запись Demo
просматривается отдельным документом с `preview=<ID>`. Для SEO редактора используется
дополнительный параметр `tab=seo`.

В редакторе Demo предпросмотр доступен только для уже сохранённой записи, включая
вкладку «Публикация». Создание записи ради предпросмотра не выполняется. Успешное
сохранение открывает `record=<ID>` созданной записи; ошибка оставляет заполненную форму.
Ссылка предпросмотра сохраняет `record`, `preview` и активную вкладку `tab` и загружает
отдельный документ. Рабочая копия полей, вкладки, порядка блоков и прокрутки хранится
отдельно в `sessionStorage` (`bypcms-demo-editor-v1:<edition>:<kind>:<ID>`), не изменяя
сохранённые материалы. Она используется в предпросмотре и восстанавливается при возврате;
после успешного сохранения удаляется. Ошибка записи рабочей копии блокирует переход в
предпросмотр и оставляет редактор открытым.

Браузерная кнопка «Назад» работает без обработчиков и возвращает предыдущий документ
редактора. «Закрыть» использует тот же переход назад, если referrer указывает именно
на эту запись; при прямом открытии предпросмотра ведёт обычной ссылкой к её редактору.
Ссылка «Материалы» всегда открывает список.

Новая запись Demo создаётся без выбранного изображения и даты публикации. Обложка,
блок изображения и Open Graph показывают пустое состояние, пока пользователь явно
не выберет файл; отмена медиатеки ничего не выбирает. Изображение можно убрать.
SEO-рекомендация открывает медиатеку вместо автоматической подстановки первого файла.
История скрыта до первого успешного сохранения. Далее показываются до 50 последних
фактических сохранений с датой, названием и статусом из демо-сессии; фиктивных версий,
автосохранений и неработающего восстановления нет. Ошибка сохранения историю не меняет.
Кнопка «Сохранить» оставляет выбранный статус, а «Сохранить и опубликовать» устанавливает
статус «Опубликовано» и текущую дату, если пользователь её ещё не указал.

## Медиатека Demo

Редактор и раздел медиатеки используют общий `DemoMediaProvider` и `MediaBrowser`.
Из окна выбора можно загрузить несколько фото с компьютера или перетаскиванием,
найти файл по имени/Alt/подписи, отфильтровать по дате и источнику, отсортировать
по дате, имени или размеру. Каталог выводит 24 файла на странице и позволяет перейти
на указанную страницу. Дата, размер и разрешение показываются только по реальным данным;
у встроенных образцов дата и размер файла неизвестны.

Метаданные, оригиналы и отдельные миниатюры хранятся в IndexedDB этого браузера.
При открытии каталога читаются метаданные; миниатюры загружаются только для текущей
страницы, оригинал — для выбранного фото. Object URL освобождаются при закрытии
или смене страницы. Файл и его метаданные записываются одной транзакцией; ошибки
отображаются по файлам, успешные загрузки остаются доступными после частичного сбоя.
Поддерживаются JPG, PNG, WebP, GIF и AVIF до 15 МБ; в отдельной медиатеке также PDF/DOC/DOCX.
Повреждённые изображения, пустые, неподдерживаемые и слишком большие файлы отклоняются.

Щелчок по фото открывает сведения; «Использовать изображение» применяет выбор
в редакторе. Отмена и Escape сохраняют материал без изменения обложки. Загруженные
файлы при этом остаются в каталоге. Загрузка не создаёт и не сохраняет материал.
Alt и подпись сохраняются в общем каталоге. Файл можно скрыть из выбора и восстановить
через фильтр «Скрытые»; оригиналы в существующих материалах остаются доступны.
Сброс данных сайта не удаляет медиатеку браузера.
Возврат страницы из кэша браузера и активация вкладки обновляют каталог. Доступна
кнопка «Обновить список»; старый ответ чтения не перезаписывает более свежую загрузку.

`node --test --test-isolation=none tests/demo-media.test.mjs` проверяет каталог
из 1031 файла, границы страниц, поиск, сортировку, фильтры, скрытие и валидацию файлов.

Ссылки строятся общей функцией `panelHref`: она сохраняет текущий путь. Поэтому Demo
одинаково работает на `demo.bypcms.ru/` и `bypcms.ru/demo/`, а Owner/Admin остаются
в `/owner/` и `/admin/`. Кнопки браузера «Назад» и «Вперёд» обрабатывает браузер.

## Проверки

`node --test tests/panels.test.mjs` проверяет построение ссылок, разметку таблиц,
пустые списки и отсутствие старой синхронизации истории. В ограниченном Windows
окружении можно добавить `--test-isolation=none`, чтобы не запускать дочерний процесс.
Production-экспорт проверяется командой `build:ftp` из `package.json`.
`node --test --test-isolation=none tests/editor-preview.test.mjs` проверяет рабочие
копии, ошибки хранилища, первое сохранение, изоляцию записей и выбор перехода «Закрыть».
`php tests/panel-bulk.test.php` проверяет серверные массовые операции на изолированной
SQLite базе, включая частичный сбой, откат транзакции и защиту системных записей.
